# OlympTrack

## Что это
Веб-приложение + Telegram-бот для школьников, которые участвуют в олимпиадах.
Централизует расписание, учёт времени, олимпиады и личные цели в одном месте.

## Проблема которую решает
Школьники ведут учёт в разных инструментах — таблицы, заметки, календари.
Из-за этого пропускают дедлайны и не видят свой прогресс.

## Основные модули
- Олимпиады: таблица с дедлайнами, статусами, результатами
- Расписание: занятия по дням, отметка пропусков
- Учёт времени: факт/план за неделю, распределение по предметам
- Список "Хочу попробовать": новые активности со статусами
- Дневник настроения: оценка 1-5, график за месяц
- ИИ-чат: отвечает на вопросы зная все данные пользователя
- Уведомления: утренняя сводка, напоминания, вечерний запрос

## Технический стек
- Frontend: HTML/CSS/JS (React опционально)
- Backend: Python (Flask или FastAPI)
- База данных: SQLite → PostgreSQL
- Telegram-бот: python-telegram-bot
- ИИ: Claude API
- Хостинг: Railway или Render

## Как работать с этим проектом
- Основной язык: Python для бэкенда
- Начинать с малого: сначала один модуль, потом расширять
- Сначала делаем модуль Олимпиады как MVP
- Все настройки пользователя задаются через онбординг
